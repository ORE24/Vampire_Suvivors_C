# 게임 규칙 문서

## 게임 목표

플레이어는 터미널 맵 안에서 몰려오는 적을 피하면서 자동 공격으로 생존한다. 적을 처치하면 경험치를 얻고, 경험치를 모으면 레벨업하여 강화 선택지를 고른다.

## 승리와 패배

- 승리 조건: 10분 동안 생존한다.
- 패배 조건: 플레이어 HP가 0이 된다.

## 조작

- 이동: `WASD` 또는 방향키
- 레벨업 선택: `1`, `2`, `3` 또는 방향키로 선택 후 `Enter` / `Space`
- 사운드 토글: `M`
- 종료: `Q`

## 맵

- MVP 맵은 1개다.
- 현재 맵은 터미널 창 크기에 맞춰 자동으로 넓어지고 높아진다.
- 최소 맵 크기는 `64 x 22`, 최대 맵 크기는 `240 x 80` 타일이다.
- 지하 묘지 느낌의 닫힌 맵으로 구성한다.
- 벽과 장애물은 이동할 수 없는 타일이다.
- 플레이어와 적은 맵 안에서만 이동한다.

## 플레이어

- 기본 HP: 12
- 경험치를 얻으면 레벨업한다.
- 피격 후 짧은 무적 시간이 있다.
- 경험치 아이템은 일정 거리 안에 들어오면 플레이어에게 끌려온다.

## 적

MVP 적은 3종이다.

| 표시 | HP | 설명 |
| --- | ---: | --- |
| `b` | 1 | 약한 적, 초반 압박용 |
| `G` | 3 | 중간 적, 기본 전투용 |
| `V` | 40 | 강한 적, 후반 위협용 |

회의에서 나온 디자인 후보는 박쥐, 좀비, 뱀파이어다. MVP에서는 모두 근접형으로 움직인다.

## 무기

현재 구현된 자동 공격 무기는 2개다.

| 무기 | 표시 | 설명 |
| --- | --- | --- |
| 마법탄 | `*` | 가장 가까운 적을 자동 조준해 발사한다. |
| 신성 오라 | `~` | 플레이어 주변 적에게 주기적으로 범위 피해를 준다. |

회의에서 나온 추가 무기 후보는 동그라미, 세모, 네모, 별이다.

## 경험치와 레벨업

- 적을 처치하면 `+` 경험치 아이템이 떨어진다.
- 경험치가 충분히 쌓이면 레벨업한다.
- 레벨업 중에는 게임이 잠시 멈춘다.
- 플레이어는 3개 강화 선택지 중 1개를 고른다.

## 랭킹

게임이 끝나면 결과가 `scores.txt`에 저장된다.

랭킹에는 다음 정보가 들어간다.

- 승리 또는 패배
- 점수
- 생존 시간
- 처치 수
- 도달 레벨

## 난이도

회의에서는 `easy`, `hard` 난이도를 고려했다. 현재 MVP는 단일 난이도이며, 이후 다음 방식으로 확장할 수 있다.

- `easy`: 적 생성 속도 느림, 강한 적 등장 지연
- `hard`: 적 생성 속도 빠름, 강한 적 조기 등장
