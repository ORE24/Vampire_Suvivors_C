# 게임 규칙 문서

## 게임 목표

플레이어는 터미널 맵 안에서 몰려오는 적을 피하면서 자동 공격으로 생존한다. 적을 처치하면 경험치를 얻고, 경험치를 모으면 레벨업하여 강화 선택지를 고른다.

## 승리와 패배

- 승리 조건: 10분 동안 생존한다.
- 패배 조건: 플레이어 HP가 0이 된다.

## 조작

- 이동: `WASD` 또는 방향키
- 난이도 선택: 설정 화면에서 `1` Easy, `2` Hard 또는 방향키 후 `Enter`
- 레벨업 선택: `1`, `2`, `3` 또는 방향키로 선택 후 `Enter` / `Space`
- 일시정지/재개: 게임 중 `Esc`
- 사운드 토글: `M`
- 현재 런 종료: 게임 중 `Q`
- 프로그램 종료: 초기 화면에서 `Q` 또는 `Esc`

## 맵

- MVP 맵은 1개다.
- 맵 크기는 `96 x 30` 타일로 고정한다.
- 터미널 창 크기, OS, 디스플레이 크기가 달라도 플레이어, 적, 장애물의 좌표는 동일한 규칙으로 유지한다.
- 전체화면 터미널 사용을 권장하지만, 터미널 크기는 게임 규칙에 영향을 주지 않는다.
- 지하 묘지 느낌의 닫힌 맵으로 구성한다.
- 벽과 장애물은 이동할 수 없는 타일이다.
- 플레이어와 적은 맵 안에서만 이동한다.

## UI와 표시

- 플레이어는 `@`로 표시한다.
- HP 바는 빨간색, XP 바는 초록색으로 표시한다.
- 적, 투사체, 경험치, 오라는 서로 다른 색상과 문자로 구분한다.

## 플레이어

- 기본 HP: Easy 14, Hard 10
- 경험치를 얻으면 레벨업한다.
- 피격 후 짧은 무적 시간이 있다.
- 경험치 아이템은 일정 거리 안에 들어오면 플레이어에게 끌려온다.

## 적

MVP 적은 3종이다.

| 표시 | HP | 특징 |
| --- | ---: | --- |
| `b` | 1 | 빠르게 접근하는 약한 적 |
| `G` | 3 | 중간 속도, 중간 피해의 기본 적 |
| `V` | 40 | 느리지만 피해와 보상이 큰 후반 적 |

회의에서 나온 디자인 후보는 박쥐, 좀비, 뱀파이어다. MVP에서는 모두 근접형으로 움직인다.
현재 적은 거리 맵 기반으로 이동해 벽에 막히면 돌아서 플레이어를 추적한다.

## 무기

현재 구현된 자동 공격 무기는 4개다.

| 무기 | 표시 | 설명 |
| --- | --- | --- |
| 마법탄 | `*` | 가장 가까운 적을 자동 조준해 발사한다. |
| 신성 오라 | `~` | 플레이어 주변 적에게 주기적으로 범위 피해를 준다. |
| 관통창 | `|` | 가까운 적을 향해 빠르게 날아가며 여러 적을 관통한다. |
| 별탄막 | `x` | 플레이어 주변 여러 방향으로 탄을 퍼뜨린다. |

## 경험치와 레벨업

- 적을 처치하면 `+` 경험치 아이템이 떨어진다.
- 경험치가 충분히 쌓이면 레벨업한다.
- 레벨업 중에는 게임이 잠시 멈춘다.
- 플레이어는 3개 강화 선택지 중 1개를 고른다.

## 일시정지

- 게임 중 `Esc`를 누르면 일시정지된다.
- 일시정지 중에는 시간, 적 이동, 공격, 경험치 이동이 진행되지 않는다.
- 다시 `Esc`를 누르면 재개된다.
- 일시정지 중 `Q`를 누르면 현재 런을 종료한다.

## 랭킹

게임이 끝나면 결과가 `scores.txt`에 저장된다.

랭킹에는 다음 정보가 들어간다.

- 승리 또는 패배
- 점수
- 생존 시간
- 처치 수
- 도달 레벨

## 난이도

시작 전 설정 화면에서 `Easy`, `Hard` 중 하나를 고른다.

- `Easy`: 플레이어 HP 14, 적 생성 속도 느림, 강한 적 등장 지연
- `Hard`: 플레이어 HP 10, 적 생성 속도 빠름, 강한 적 조기 등장
