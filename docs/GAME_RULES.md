# 게임 규칙 문서

## 게임 목표

플레이어는 터미널 맵 안에서 몰려오는 적을 피하면서 자동 공격으로 생존한다. 적을 처치하면 경험치를 얻고, 경험치를 모으면 레벨업하여 강화 선택지를 고른다.

## 승리와 패배

- 승리 조건: 3~5분 묘지 생존 구간을 넘긴 뒤 시작맵 지형에서 진행되는 최종 보스전을 완료하고 보스를 처치한다.
- 패배 조건: 플레이어 HP가 0이 된다.

## 조작

- 이동: `WASD` 또는 방향키
- 난이도 선택: 설정 화면에서 `1` Easy, `2` Hard 또는 방향키 후 `Enter`
- 레벨업 선택: `1`, `2`, `3` 또는 방향키로 선택 후 `Enter` / `Space`
- 일시정지/재개: 게임 중 `Esc`
- 사운드 토글: `M`
- 현재 런 종료: 게임 중 `Q`
- 프로그램 종료: 초기 화면에서 `Q` 또는 `Esc`

## 맵

- 게임 시작 후 0~3분은 기존 시작맵에서 진행한다.
- 게임 시간이 3분(180초)을 넘으면 후반 전용 묘지맵으로 전환되고, 5분까지 묘지에서 생존해야 한다.
- 게임 시간이 5분(300초)을 넘으면 시작맵과 같은 지형의 보스 아레나로 전환되고 최종 보스전이 시작된다.
- 맵 크기는 `96 x 30` 타일로 고정한다.
- 터미널 창 크기, OS, 디스플레이 크기가 달라도 플레이어, 적, 장애물의 좌표는 동일한 규칙으로 유지한다.
- 전체화면 터미널 사용을 권장하지만, 터미널 크기는 게임 규칙에 영향을 주지 않는다.
- 지하 묘지 느낌의 닫힌 맵으로 구성한다.
- 묘지맵은 더 많은 장애물과 중앙 묘지 스폰으로 3~5분 생존 압박감을 높인다.
- 맵 전환 시 플레이어, 적, pickup은 가까운 빈칸으로 이동하고 벽 안의 투사체는 제거한다.
- 전환 후 5초 동안 `묘지가 깨어났습니다... THE GRAVEYARD AWAKENS` 경고가 표시된다.
- 보스 아레나 전환 후 5초 동안 보스전 시작 경고가 표시된다.
- 벽과 장애물은 이동할 수 없는 타일이다.
- 플레이어와 적은 맵 안에서만 이동한다.

## 최종 보스전

- 1페이즈 보스는 보호막 상태로 등장하며, 보스 UI가 현재 페이즈, 상태, 목표, 퍼즐 진행도, 특수 상태를 고정 표시한다.
- 퍼즐 1은 `R/B/G/Y` 제단 중 보스가 제시한 3개 순서를 밟는 순서 퍼즐이다. 실패하면 진행도가 초기화되고 추가 몬스터가 소환된다.
- 첫 딜타임은 보스 HP 50%에서 자동 종료되고 피의 구슬 운반 퍼즐로 전환된다.
- 퍼즐 2는 `O` 구슬을 중앙 `A` 제단으로 3회 운반한다. 구슬 소지 중 피격되면 현재 위치에 구슬을 떨어뜨리고, 소지 중 이동속도가 감소한다.
- 두 번째 딜타임에서 1페이즈 보스를 쓰러뜨리면 2페이즈 분신 4개가 생성된다.
- 2페이즈는 진짜 보스가 15초마다 교체된다. 진짜 보스가 한 봉인 제단 근처에 있을 때 플레이어가 다른 `A` 제단을 밟으면 봉인이 성공한다.
- 봉인 3회 성공 시 가짜 분신이 제거되고 최종 딜타임이 시작된다. 최종 보스 HP를 0으로 만들면 승리한다.
- 보스전 중 보스는 `&` 그림자를 생성한다. 적이 그림자에 닿으면 플레이어 HP가 1 감소하며, 그림자 피해에는 1초 쿨다운이 있다.
- 보스전 중 `W/A/S/D` 중 하나가 6초 동안 금지될 수 있으며, 해당 방향 입력은 무시된다.
- 보스전 중 추가 몬스터 웨이브가 주기적으로 발생하고, 퍼즐 진행 중에는 간격이 더 짧아진다.

## UI와 표시

- 플레이어는 `@`로 표시한다.
- HP 바는 빨간색, XP 바는 초록색으로 표시한다.
- 적, 투사체, pickup, 오라는 서로 다른 색상과 문자로 구분한다.

## 플레이어

- 기본 HP: Easy 14, Hard 10
- 경험치를 얻으면 레벨업한다.
- 피격 후 짧은 무적 시간이 있다.
- 경험치 pickup은 일정 거리 안에 들어오면 플레이어에게 끌려온다.

## 적

MVP 적은 3종이다.

| 표시 | HP | 특징 |
| --- | ---: | --- |
| `b` | 1 | 빠르게 접근하는 약한 적 |
| `G` | 3 | 중간 속도, 중간 피해의 기본 적 |
| `V` | 40 | 느리지만 피해와 보상이 큰 후반 적 |

회의에서 나온 디자인 후보는 박쥐, 좀비, 뱀파이어다. MVP에서는 모두 근접형으로 움직인다.
현재 적은 거리 맵 기반으로 이동해 벽에 막히면 돌아서 플레이어를 추적한다.
- 묘지맵에서는 중앙 근처의 4개 묘지에서 추가 적 웨이브가 주기적으로 나온다.
- 묘지 추가 웨이브는 일반 외곽 웨이브와 별도로 발생하며, 후반에는 중간/강한 적 비중이 높다.

## 무기

현재 구현된 자동 공격 무기는 4개다.

| 무기 | 표시 | 설명 |
| --- | --- | --- |
| 마법탄 | `*` | 가장 가까운 적을 자동 조준해 발사한다. |
| 신성 오라 | `~` | 플레이어 주변 적에게 주기적으로 범위 피해를 준다. |
| 관통창 | `|` | 가까운 적을 향해 빠르게 날아가며 여러 적을 관통한다. |
| 별탄막 | `x` | 플레이어 주변 여러 방향으로 탄을 퍼뜨린다. |

- 투사체는 벽이나 장애물에 닿으면 사라지며, 벽 너머의 적을 맞히지 않는다.

## Pickup과 레벨업

- 적을 처치하면 `+` 경험치 pickup이 떨어진다.
- Vampire Survivors의 Experience Gem, Heal Pack, Vacuum, Rosary를 참고해 현재 게임에는 다음 pickup을 넣는다.
  - `+` XP: 경험치와 점수를 얻는다.
  - `H` 구급상자: HP를 일부 회복한다.
  - `M` 진공: 화면에 남은 XP를 한 번에 끌어모은다.
  - `R` 로자리: 현재 활성 적을 처치한다.
  - `?` 도박사의 주사위: HP 회복, 폭발, 좋은 무기, 무작위 pickup 효과 중 하나가 랜덤으로 발동하고, 발동한 효과 이름을 5초간 화면 하단에 표시한다.
  - `B` 폭주 탄창: 5초 동안 발사 쿨타임이 거의 사라지고 랜덤 방향 탄막이 터진다.
  - `C` 보물상자: 주변에 XP와 구급상자 pickup을 여러 개 뿌린다.
- 경험치가 충분히 쌓이면 레벨업한다.
- 레벨업 중에는 게임이 잠시 멈춘다.
- 플레이어는 3개 강화 선택지 중 1개를 고른다.

## 사운드

- Windows 기본 WinMM API로 `assets/audio/*.wav`를 비동기 재생한다.
- 선택 이동, 선택 확정, 총쏘기, XP 획득, 회복, 파워 pickup, 레벨업, 피격, 게임오버, 승리는 서로 다른 wav 효과음을 사용한다.

## 미니 이벤트

- 30초마다 랜덤 미니 이벤트가 발생한다.
- `피의 안개`: 일정 시간 화면 일부가 안개로 가려지고 적이 더 빠르게 움직인다.
- `박쥐 폭풍`: 약한 박쥐 적이 한 번에 많이 등장한다.

## 일시정지

- 게임 중 `Esc`를 누르면 일시정지된다.
- 일시정지 중에는 시간, 적 이동, 공격, 경험치 이동이 진행되지 않는다.
- 다시 `Esc`를 누르면 재개된다.
- 일시정지 중 `Q`를 누르면 현재 런을 종료한다.

## 랭킹

게임이 끝나면 결과가 `scores.txt`에 저장된다.

랭킹에는 다음 정보가 들어간다.

- 승리 또는 패배
- 점수
- 생존 시간
- 처치 수
- 도달 레벨

## 난이도

시작 전 설정 화면에서 `Easy`, `Hard` 중 하나를 고른다.

- `Easy`: 플레이어 HP 14, 적 생성 속도 느림, 강한 적 등장 지연
- `Hard`: 플레이어 HP 10, 적 생성 속도 빠름, 강한 적 조기 등장
