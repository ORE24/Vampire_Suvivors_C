# 마일스톤 문서

## 최종 목표

2026-05-30까지 팀원이 직접 설명할 수 있는 터미널 기반 뱀파이어 서바이벌 MVP를 완성한다.

## 마일스톤 1: MVP 기반 완성

- 목표 기간: 2026-05-17
- 담당: `JAE`
- 상태: 완료

완료 기준:

- 터미널에서 실행된다.
- Windows Visual Studio 2022 실행 방법이 있다.
- 초기 화면, 랭킹 화면, 게임 화면이 있다.
- 이동, 자동 공격, 적 이동, 경험치, 레벨업이 동작한다.
- 맵은 `96 x 30` 고정 크기로 동작한다.
- 적은 벽을 돌아 플레이어를 추적한다.
- `Esc` 일시정지/재개가 동작한다.
- HP와 XP UI 색상이 구분된다.
- 시작 전 `Easy`, `Hard` 난이도를 선택할 수 있다.
- 자동 공격 무기 4종이 동작한다.
- 적 3종은 속도, 피해, 보상이 차별화되어 있다.
- GitHub 저장소와 팀 브랜치가 준비되어 있다.

## 마일스톤 2: 팀별 기능 개선

- 목표 기간: 2026-05-18 ~ 2026-05-24
- 담당: `JAE`, `TAE`, `JONG`
- 상태: 예정

담당 작업:

- `JAE`: 최신 `JAE` 변경을 `main`에 통합 준비, Windows 실행 안정성 유지, PR 검증, 스모크 테스트 관리
- `TAE`: 난이도와 적 밸런스 추가 조정, 이동 감각 개선
- `JONG`: 무기 4종 밸런스 추가 조정, UI 개선, 사운드 이벤트 구분 개선

완료 기준:

- 각자 브랜치에 작업 커밋이 올라간다.
- 주요 변경은 Pull Request로 공유된다.
- 최소 1명이 리뷰한 뒤 `main`에 합친다.
- Visual Studio 빌드와 스모크 테스트가 통과한다.
- 자세한 작업 현황은 [협업 작업 현황판](TEAM_TASKS.md)을 기준으로 확인한다.
